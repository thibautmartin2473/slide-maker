# Acteurs par levier

**Répond à :** attribuer chaque levier à ses porteurs, pour que la
recommandation devienne un **qui-fait-quoi**. Version légère d'une matrice
RACI, faite pour être lue d'un coup d'œil.

## Anatomie : tableau leviers × acteurs (version une page)

| Zone | Part | Contenu |
|---|---|---|
| Titre-message | ~12 % | « Cinq leviers, chacun avec un porteur désigné ; l'État n'en porte qu'un » |
| **En-têtes d'acteurs** | ~10 % | 3-6 colonnes, un **picto** + libellé court par acteur (collectivité, État, industriel…) |
| **Colonne leviers** | ~40 % de la largeur | levier numéroté (grand numéro), verbe d'action souligné, une phrase |
| **Cellules** | ~45 % | pastille pleine = porteur, pastille creuse = contributeur, vide = non concerné |
| Pied | ~6 % | légende pleine / creuse, `Source:` |

## Le mécanisme

**On lit « qui » avant « quoi »** : les colonnes pleines désignent les acteurs
chargés, et une colonne vide se remarque (un acteur absent est un message).
Numéroter les leviers comme les freins (frein 3 et levier 3) rend la réponse
traçable jusqu'au diagnostic.

## La charge

5-8 leviers × 3-6 acteurs. Au-delà de 6 acteurs, les pictos deviennent
illisibles : regrouper (public / privé / associatif).

## Variantes vues

- **Levier par page, rangée de pictos** (Vertone ESS p. 64) : sous le titre du
  levier, 5 pictos d'acteurs, **actifs dans l'accent, inactifs en gris**, puis
  le texte et un encadré « Recommandation ». Pour un rapport long.
- **Freins / leviers en miroir** (Vertone) : frein n à gauche, levier n à
  droite, même numéro, la correspondance 1-pour-1 se lit en ligne.
- **Tableau barrière → action** (Strategy& p. 56) : grand numéro, barrière,
  action avec verbes soulignés, acteur responsable ; version prescriptive du
  [statut par chantier](statut-par-chantier.md).
- **Recommandations codées par pastille** (OW EBF p. 12) : N recommandations,
  chacune rattachée par une pastille de teinte à 3 familles légendées.
- **Série de barrières à titre préfixé** (BCG IRA s. 8-13) : même gabarit sur N
  slides, `Barrière | message`, preuves à gauche, exemple à droite, tracker de
  coin, la version « une barrière par page ».

## Rendu

- **Paysage** : tableau leviers × acteurs sur une page.
- **Portrait** : une carte par levier, empilées ; en tête de carte, la rangée
  de pictos (actifs / inactifs), puis le texte. C'est le rendu natif de Vertone.

## À ne pas confondre

Avec le [diagnostic de causes](diagnostic-causes.md), qui dit **pourquoi**
chaque action ; ici on dit **qui**.
