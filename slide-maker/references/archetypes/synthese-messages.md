# Synthèse en messages

**Répond à :** permettre au lecteur de **s'arrêter après une page**. Chaque
message est une phrase complète et affirmative ; ensemble, ils forment le
raisonnement du deck dans l'ordre.

## Anatomie : une liste numérotée, une ligne par message

| Zone | Part | Contenu |
|---|---|---|
| Titre | ~10 % | « Synthèse » est admis ici (c'est une rubrique) ; mieux : le message 1 |
| **Numéros** | ~8 % de la largeur | grands chiffres (1-6) dans la police display, en accent |
| **Messages** | ~50 % | la phrase-message en gras, 1-2 lignes |
| **Justification** | ~40 % | 1-3 puces ou le chiffre qui prouve, en neutre |
| Séparateurs | - | filets fins entre lignes |
| Pied | ~5 % | renvoi aux sections (`→ p. 12`) |

## Le mécanisme

**Lire uniquement le gras donne l'histoire.** La justification est là pour le
lecteur qui doute, pas pour le lecteur pressé. Les numéros créent un
engagement : le deck reprend ensuite les messages dans le même ordre (tracker
ou intercalaires), ce qui fait de cette page le sommaire.

## La charge

4 à 7 messages. Au-delà, deux niveaux (messages + sous-messages) ou deux pages
(Strategy& : une slide par étape du raisonnement, 7 slides).

## Variantes vues

- **Key takeaways numérotés** (OW NAIC, CDI 22.A) : gros numéro, takeaway en
  gras, justification en puces. La forme canonique.
- **Tableau conclusion / justification** (Strategy& V2G p. 4) ou **tableau de
  takeaways** (OW CDI 22.A) : pour un comité qui vérifie ligne par ligne.
- **Sommaire-synthèse questions / insights** (McKinsey HHS, NCDOT) : colonne
  gauche = la question, droite = ce qu'on a trouvé.
- **Tuiles en bandes** (PMP Arcom p. 36) : une bande par thème, pastille
  numérotée, deux chiffres géants, conclusion à droite dont les mots-clés
  reprennent la couleur de la bande. Slide de **clôture**, pas d'ouverture ;
  cousine des [KPI tiles](kpi-tiles.md).
- **Executive summary à intercalaires** (RB PFA 2025, CLEPA 2025) : N messages,
  chacun réutilisé comme intercalaire de section.
- **Exec summary textuel** (BCG) : bullets à deux niveaux sur 2-4 pages ; à
  éviter en case, trop long.

## Rendu

- **Paysage** : une ligne par message, trois colonnes (numéro / message /
  justification).
- **Portrait** : même liste, justification **sous** le message au lieu d'à
  côté ; 5-7 messages tiennent sur une page A4. C'est l'executive summary de
  tête d'un rapport.

## À ne pas confondre

Avec le [graphe et verdict](graphe-et-verdict.md), qui conclut **un** exhibit ;
avec les [piliers en blocs](piliers-en-blocs.md), qui présentent des piliers,
pas des messages.
